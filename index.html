Dungeon Tracker

Version 1.5 · firmware for the M-VAVE FM-1

A four-track tracker groovebox whose HOME screen is a dungeon crawl played by your song. Eight engines in four families (FM, WAVE, AMIGA'D, SUB), DICE sound design, SOUND MORPH and a party of eight classes.

Download the firmware The 1.5 release: dungeon-tracker-1.5.fwsc, with install and recovery steps. Use it at your own risk. Try it in the browser The emulator runs the real 1.5 firmware code with no FM-1 needed. Press Switch on to start it. Editor Edit sounds, patterns and the party, and back up your FM-1 over USB MIDI (Chrome or Edge). Add ?mock=1 to try it without the device. Manual Everything Dungeon Tracker does, page by page.
